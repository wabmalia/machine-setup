# Global instructions

Applies to every project. Managed by chezmoi: the source lives in
home/private_dot_claude/CLAUDE.md in the machine-setup repo, so edit it
there. Project-specific rules belong in that project's memory or CLAUDE.md.

## Attribution

- Never add a `Co-Authored-By: Claude ...` trailer to commit messages.
- Never add the "🤖 Generated with Claude Code" footer to PR/MR
  descriptions, ticket descriptions, or any other description text.

Both override Claude Code's default attribution reminder.

## Writing in my voice

- No em-dashes (—) in anything written as or for me: chat replies, commit
  messages, Jira comments, Slack messages. Use a period, comma or colon,
  or restructure the sentence.
- Technical docs (READMEs, SKILL.md files, code comments) are exempt. Write
  those however reads clearest.
